# STEAL AN EGG: ULTIMATE HEIST

Первая версия оригинальной Roblox-игры: **кража → погоня → доставка → инкубация → питомец → улучшение**. Luau + Rojo, без чужих моделей, обязательных покупок и выдуманных Asset ID.

Это исходный проект и собранный place для проверки в Roblox Studio. В Linux выполнены 76 автоматических тестов, компиляция всех 27 игровых скриптов, строгий анализ 10 общих модулей и сборка `.rbxl` / `.rbxlx`. Roblox Engine здесь недоступен: полноценная игровая готовность **ещё не подтверждена**. Подробные статусы: [docs/QA.md](docs/QA.md).

## Самый простой запуск — без терминала

1. [Скачайте сборку StudioFix4](https://github.com/rintex/steal-an-egg/raw/refs/heads/main/StealAnEgg_StudioFix4.rbxl). Файл также находится в корне репозитория.
2. Установите Roblox Studio с официального сайта Roblox на Windows или macOS и войдите в аккаунт.
3. В Studio выберите **File → Open from File…**, откройте скачанный `.rbxl` (актуальная сборка — `StealAnEgg_StudioFix4.rbxl`).
4. Нажмите **Play / F5**. Карта уже встроена в готовый файл и видна до Play; запуск включает персонажа, интерфейс и игровые действия.
5. Идите по золотым плиткам через ворота. У гнезда удерживайте **E**, затем бегите обратно. Маркер укажет ваше убежище.
6. Доставьте яйцо на **свой** зелёный круг. Подойдите к своему инкубатору и удерживайте **E**. Первое яйцо вылупляется за 8 секунд.
7. Откройте **Снаряжение** для улучшений; **Коллекция** — для инкубации и выбора активного питомца.

Для альтернативного формата доступен [StealAnEgg.rbxlx](https://github.com/rintex/steal-an-egg/raw/refs/heads/main/StealAnEgg.rbxlx). Его также можно открыть через File → Open from File.

В Studio по умолчанию используется временный прогресс: после Stop он исчезнет. Никаких ключей API для этого не нужно.

| Действие | Компьютер | Геймпад | Телефон |
| --- | --- | --- | --- |
| Движение / прыжок | WASD / Space | Стик / стандартный прыжок | Стандартные кнопки Roblox |
| Бег | Удерживать Shift | L3 | Кнопка «Бег», переключение |
| Рывок | Q | B | «Рывок» |
| Взять / инкубировать | Удерживать E | Стандартный prompt | Удерживать prompt |
| Бросить | G | D-pad вниз | «Бросить» |
| Перехват | F | X | «Перехват» |

Бег тратит выносливость; рывок проверяет препятствия и землю. Перехваты доступны только вне хаба, без защиты, на расстоянии до 7 studs. После входа действует 180 секунд защиты; после потери — 20 секунд. Сохранённая коллекция не крадётся.

## Содержимое первой версии

- Процедурный хаб, 8 персональных убежищ, магазин, доски, мост и один Green Meadow с тремя гнёздами, укрытиями и скрытой боковой тропой.
- Каталог **24 яиц** восьми редкостей; в текущем биоме появляются **6**, ещё 18 подготовлены как данные будущих биомов.
- Серверное владение яйцом, переноска на сварном креплении без столкновений, бросок, защита от двойного подбора и выдачи награды, лимит передач, обработка смерти/выхода.
- Наседки с 8 состояниями, подозрением, предупреждением перед атакой, коротким выпадом, восстановлением, путями через PathfindingService и возвратом.
- Выносливость, бег, рывок, проверка бюджета горизонтального перемещения и слишком долгого нахождения в воздухе. Это базовые ограничения, а не доказанная защита от всех эксплойтов.
- Инкубация с серверным временем и сохранёнными сроками, питомцы на пьедестале, один активный бонус восстановления, ограниченный доход только при недавней активности.
- Монеты, XP, уровни, 5 ограниченных улучшений, серии, оценки побега, 4% визуальной мутации, награда за найденную тропу.
- Ежедневные цели: 3 доставки и 1 вылупление, однократная награда, сброс в 00:00 UTC.
- Golden Egg Rush раз в 5 минут на 65 секунд, отдельное золотое гнездо и хранитель. События не перекрываются.
- UI, локальный указатель цели, короткое раскрытие питомца с пропуском, переноска, мобильные кнопки, отдельная портретная компоновка, настройки эффектов и звука.
- Таблица игроков Roblox: Coins, Eggs, Level; личные достижения и рекорды.
- DataStore: ограниченные повторы, автосохранение каждые 45 секунд, выход, BindToClose, блокировка сессии на 180 секунд, проверка схемы и уникальных UID.

**Не реализованы:** ограбление инвентаря убежищ, семь следующих биомов и их способности, командные миссии, пять разных типов событий, глобальные лидерборды, интерфейс друзей, торговля, косметические покупки и ProcessReceipt. Нет кнопок, имитирующих эти функции. Питомцы пока используют одну стилизованную процедурную форму. Аудиослоты намеренно пустые — добавляйте только разрешённые аудиоресурсы. Это первая версия, а не все 32 раздела ТЗ.

## Сборка и редактирование исходников

Нужны Rojo **7.6.1**, Luau CLI **0.695** и Python 3.10+; для дополнительных проверок native instances — Lune **0.11.0**. Версия Rojo также закреплена в `aftman.toml`.

В подготовленной Linux-среде:

```bash
cd /workspace/steal-an-egg
bash scripts/bootstrap-tools.sh
python3 scripts/check.py
```

Скрипт установки использует TLS и закреплённые SHA-256 архивов. Все программы устанавливаются вне репозитория: `/workspace/tools`. Устанавливаются Rojo, Luau и Lune. Сборка и тесты создают только игнорируемый `build/`.

На своём компьютере установите официальные Rojo и Luau CLI, добавьте их в PATH и выполните из папки проекта:

```bash
python scripts/check.py
```

Можно задать пути через `ROJO`, `LUAU`, `LUAU_COMPILE`, `LUAU_ANALYZE`, `LUNE`. Полная сборка с готовой картой выполняется через `python scripts/check.py` и требует Lune. Обычная сборка Rojo без Lune содержит скрипты и создаёт карту только после Play:

```bash
rojo build default.project.json -o StealAnEgg.rbxl
```

Для живого редактирования запустите `rojo serve default.project.json` **на том же компьютере, где работает Studio**, затем подключитесь официальным плагином Rojo. Сервер Rojo в облаке не является запущенной игрой Roblox.

## Проверка настоящих сохранений

1. Сначала опубликуйте place как **отдельную закрытую тестовую игру** через File → Publish to Roblox. Установите максимум **8 игроков** в настройках experience/place.
2. В опубликованной игре DataStore включается автоматически. Сыграйте, доставьте яйцо, дождитесь автосохранения или выйдите, затем повторно войдите и сравните прогресс.
3. Для проверки DataStore именно в Studio: включите **Enable Studio Access to API Services** в Game Settings / Security и добавьте Workspace boolean attribute `EnableStudioDataStore = true` **до Play**.
4. Используйте отдельный тестовый place: доступ Studio к API может затронуть данные соответствующей опубликованной игры.
5. При недоступных данных вход отклоняется, а пустой профиль не записывается поверх существующего. При занятой сессии подождите завершения старой сессии; после аварийного завершения lease истекает через 180 секунд.

Хранилище: `EggHeist_Profiles_v1`, ключ `u_<UserId>`. Неизвестная или повреждённая схема отклоняется; автоматической миграции неизвестных версий нет. Сейчас существует только схема v1. Перед её изменением нужен явный проверяемый переход и резервная копия. Во время длительного сбоя последние несохранённые действия могут откатиться — абсолютная гарантия отсутствия потерь не заявляется.

## Структура и баланс

```text
src/shared/Config/        Яйца, биомы, экономика, улучшения, хранитель, аудиослоты
src/shared/Domain/        Чистые правила, состояния яйца, инкубация, валидация профиля
src/server/Services/      Мир, данные, яйца, AI, движение, прогрессия, события, координатор
src/server/Bootstrap.server.lua
src/client/Controllers/   HUD, движение, эффекты, указатель обучения
src/client/Bootstrap.client.lua
tests/                   Доменные тесты и тесты настоящих сервисов с подменой Roblox API
scripts/                 Воспроизводимая установка, проверки и сборка
```

`GameService` передаёт сервисам зависимости и состояние сессии. Модули не загружают друг друга циклически. Чистые правила используются и сервером, и тестами; клиент отправляет только намерения. Он не задаёт награды, цены, UID новых предметов или значение скорости. Тяжёлые операции DataStore и построение путей вынесены из общего игрового тика; декорации не имеют собственных циклов.

Баланс редактируется в `EconomyConfig.lua`, `UpgradeConfig.lua`, `GuardianConfig.lua`, `EggConfig.lua`. Отключённый биом нельзя включать одной галочкой и считать готовым: сначала нужны карта, механики и тесты. Некоторые фиксированные пороги находятся в чистых правилах и явно покрыты тестами; меняйте их вместе с тестами.

## Репозиторий и обновлённый интерфейс

Исходники и готовый `StealAnEgg.rbxl` находятся в ветке `main` репозитория [rintex/steal-an-egg](https://github.com/rintex/steal-an-egg). Для разработки:

```bash
git clone https://github.com/rintex/steal-an-egg.git
cd steal-an-egg
```

После сборки актуальный place создаётся в `build/`. Корневой `StealAnEgg.rbxl` — публикуемая копия проверенной сборки. `build/` и логи не отправляются в Git.

В обновлении интерфейса: компактные тёмные HUD-карточки с бирюзовыми и янтарными акцентами; стабильное меню, поиск и фильтры, ленивые 3D-превью, отдельная компоновка узких и горизонтальных экранов, реальные состояния кнопок, управление геймпадом и настройки доступности. Подробности, официальные источники и ограничения проверки — [docs/UI-UPDATE.md](docs/UI-UPDATE.md).

Полное исходное задание сохранено в [docs/SPEC.ru.md](docs/SPEC.ru.md). Следующие этапы и ограничения — в [docs/ROADMAP.md](docs/ROADMAP.md).

Если загрузка в Studio не завершилась, новая сборка показывает код STUDIO-FIX-04 прямо на экране. Сообщите код и строку под ним. Для запуска с игроком используйте Play/F5. Серверные и клиентские этапы теперь имеют отдельную обработку ошибки вместо бесконечного ожидания.
