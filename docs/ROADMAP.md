# Границы первой версии и следующий порядок работы

Сейчас подготовлен первый Green Meadow, основная прогрессия, перехваты переносимых яиц, одно событие и исходники сохранений. Автоматическая проверка за пределами Roblox завершена; в первую очередь нужен прогон Studio из QA.md и исправление найденного. Ни один другой биом пока не объявлен готовым.

1. Проверить основной цикл на реальном сервере: prompt/сварка/AI/падение/доставка/инкубация, затем R6/R15, задержка сети, телефон и DataStore. Настроить скорость хранителя и допуски античита по результатам.
2. После проверки добавить Crystal Caves как второй цельный опыт: тоннели, предупреждаемый удар голема, укрытия и маршрут. Затем по одному добавлять следующие биомы; текущие 24 записи каталога служат данными, а не заменой уровней.
3. Ограбления убежищ требуют отдельного протокола: доступен только ограниченный застрахованный лут, уведомление/окно защиты, лимиты по паре игроков, серверная проверка дистанций, восстановление транзакции при выходе обеих сторон. Перед переносом сохраняемых уникальных предметов между профилями нужен устойчивый журнал транзакций. Нынешние перехваты касаются только ещё не сохранённых физических яиц.
4. Расширить оригинальные модели питомцев, разрешённое аудио, анимации, разнообразные способности с общим пределом бонусов; улучшить визуал после проверки на телефоне.
5. Добавить кооперативную цель события, новые события, глобальные OrderedDataStore-лидерборды и социальные элементы с отдельными тестами API и бюджетов.
6. Косметическую монетизацию подключать только после назначения настоящих Product/GamePass ID владельцем игры. Для Developer Products необходим ProcessReceipt с устойчивой идемпотентностью, возвратом NotProcessedYet до надёжной выдачи и тестами повторных чеков. В текущей версии оплачиваемых действий нет.

Все эти пункты — оставшаяся разработка, а не скрытые реализованные возможности. Не публиковать игру как завершённую по одному успешному `rojo build`.
